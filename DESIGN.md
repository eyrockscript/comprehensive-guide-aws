# AWS Comprehensive Guides - Visual Identity

## Style Prompt

Tecnico, profesional y moderno. Estilo cloud computing corporativo con acentos energeticos en naranja AWS. Tipografia clara y legible para contenido tecnico. Transiciones fluidas que evocan la velocidad y escalabilidad de la nube.

## Colors

- **Primary**: #FF9900 (AWS Orange) - Para acentos, CTAs, elementos de energia
- **Secondary**: #232F3E (AWS Dark) - Fondos principales, tarjetas
- **Background**: #0A0E14 (Deep Dark) - Canvas principal
- **Text Primary**: #FFFFFF - Textos principales
- **Text Secondary**: #A0AEC0 - Textos secundarios, metadata
- **Accent**: #00A8E8 (Cloud Blue) - Elementos de highlight

## Typography

- **Headings**: Inter, system-ui, sans-serif - Peso 600-700
- **Body**: Inter, system-ui, sans-serif - Peso 400-500
- **Monospace**: JetBrains Mono, monospace - Para codigo y datos tecnicos

## What NOT to Do

- No usar gradientes fuertes o multiples colores
- No usar sombras excesivas o difuminadas
- No usar animaciones bruscas o repentinas
- No usar bordes redondeados excesivos (max 8px)
- No mezclar estilos flat con skeuomorfismo
